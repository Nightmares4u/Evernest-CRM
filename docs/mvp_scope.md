# MVP Scope

## Include now

- office setup
- agent setup
- lead intake
- lead assignment
- lead status updates
- agent activity logging
- audit flags
- dashboard shell
- daily summary scaffolding
- raw WhatsApp webhook logging

## Exclude for now

- mobile app
- chatbot
- complex commission engine
- drag-and-drop kanban
- document uploads
- automated WhatsApp replies
- advanced RBAC
- public customer portal
